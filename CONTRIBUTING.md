# Contributing to Imag-Eval

First of all, thank you for considering contributing to Imag-Eval! 🎉

Whether you are fixing a typo, improving documentation, evaluating a new model, extending the benchmark, or proposing a research idea, your contribution is welcome.

Imag-Eval was built incrementally and is actively evolving. Community feedback and contributions play an important role in improving the benchmark, evaluation methodology, and overall reproducibility.

---

## Ways to Contribute

There are many ways to help the project:

### 📖 Documentation

- Improve README sections
- Add tutorials and examples
- Fix typos, broken links, or unclear explanations
- Improve installation and setup instructions

### 🐛 Bug Reports

If you encounter a bug:

1. Search existing issues first.
2. Open a new issue if the problem has not been reported.
3. Include:
   - Operating system
   - Python version
   - Relevant hardware information
   - Error logs
   - Steps required to reproduce the problem

A minimal reproducible example is always appreciated.

---

### 🚀 Feature Development

Examples of useful feature contributions:

- Additional evaluation skills
- New robustness tests
- Additional T2I model integrations
- Improved evaluation pipelines
- Better annotation workflows
- MPS support
- AMD support
- Performance optimizations

For large features, please open an issue first to discuss the design before investing significant development effort.

---

### 📊 Benchmark Results

We welcome benchmark evaluations for additional Text-to-Image models.

When submitting benchmark results, please provide:

- Generated images
- Generation seed(s)
- Inference parameters
- Model version
- Evaluation settings
- Annotation methodology

Submissions may be independently reproduced before being added to the public leaderboard.
